# Security Tools in C 

مستودع مخصص للتكليفات البرمجية الخاصة بتحليل السجلات وفحص الملفات الثنائية بلغة C لمحللي الـ SOC.

## الأدوات المتاحة:
1. **Log File Parser (log.c)**: أداة لتصفية وفحص السجلات الأمنية سطرًا بسطر والبحث عن الأنشطة المشبوهة دون استهلاك الذاكرة.
2. **Hexadecimal Viewer (hex_view.c)**: أداة لعرض قيم البايتات الخام للملفات بصيغة الهكس والـ ASCII لفحص هيدر الملفات والتواقيع الرقمية.
